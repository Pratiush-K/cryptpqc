Break a toy RSA key

This breaks a toy RSA key. The quantum speed-up in Shor's algorithm is the period-finding step; here it is simulated by brute force, so it only works on tiny keys. Everything else (picking a, taking gcds, rebuilding the private key) is the real attack.

Hybrid encryption

Crypt combines a classical and a post-quantum key exchange, so an attacker has to break both. Same crypt_keygen / crypt_encrypt / crypt_decrypt API you'd call from code. Each run generates a fresh keypair.
